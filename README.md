# Taskflow - React practice project

A deliberately simple React + Vite practice website.

## Run it

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Project structure

- `src/App.jsx`: keeps the shared page state and connects the components.
- `src/App.css`: styles the website sections and dashboard.
- `src/index.css`: global browser defaults and basic resets.
- `src/components/`: the public website sections.
- `src/dashboard/`: the client dashboard.

## Practice tasks

1. Change the hero heading and paragraph.
2. Add a fourth starting feature card.
3. Add a new FAQ item.
4. Add an input to the dashboard for a card icon.
5. Add an Edit button to each dashboard card.
6. Make the dashboard navigation switch between two sections.

The dashboard is a frontend demo. It does not use a backend or database; refreshing the page resets the cards.
